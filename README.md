# Discord Currency & Crypto Converter Bot v2

A fast, reliable, and open-source Discord bot built with Python that fetches live fiat and cryptocurrency exchange rates.

![Demo](demo2.jpg)

## Features
- **Live Fiat Rates:** Uses the [ExchangeRate-API](https://www.exchangerate-api.com/) for accurate global currencies.
- **Crypto Support:** Fetches real-time crypto prices (BTC, ETH, SOL, DOGE, etc.) using the [CoinGecko API](https://www.coingecko.com/en/api).
- **Slash Commands:** Fully supports modern Discord `/convert` slash commands.
- **Clean UI:** Displays results in a beautifully formatted Discord Embed card.
- **Smart Formatting:** Handles both large fiat numbers and small crypto decimal values gracefully.
